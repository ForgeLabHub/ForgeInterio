# Матрица проверок

| Проверка | Что доказывает | Команда | CI |
| --- | --- | --- | --- |
| Тесты (15) | аутентификация, квиз и защитные свойства работают | `make test` | `ci.yml` → `tests` |
| ruff | статические правила соблюдены | `make lint` | `ci.yml` → `tests` |
| Регрессии безопасности | нет пароля в коде, нет CORS-звёздочки, админ-код из окружения | `make test` | `ci.yml` → `tests` |
| Запуск без опциональной конфигурации | без SMTP и без `ADMIN_CODE` приложение работает (админ-вход 503) | старт + `/` | `ci.yml` → `runtime` |
| Smoke тест живого инстанса | маршруты отвечают, админ-данные закрыты | `make smoke-test` | вручную после деплоя |
| Документация согласована | ссылки живые, спецификации модулей полны | `make docs-check` | `ci.yml` → `docs` |
| Проверка хоста | окружение и секреты в порядке до запуска | `make doctor` | локально |

## Что не проверяется автоматически

- Развёртывание на Render: `render.yaml` описан, но деплой не автоматизирован в CI.
- Сохранность `data.db` при перезапуске хостинга — зависит от подключённого диска.
- Поведение под нагрузкой и попытки перебора пароля (rate limit не реализован).
