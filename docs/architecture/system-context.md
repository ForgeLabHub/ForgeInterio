# Контекст системы

## Что это

Interio — небольшое веб-приложение для подбора дизайна интерьера: регистрация и вход,
интерактивный квиз, админ-панель заявок. Один процесс FastAPI, шаблоны и статика,
SQLite.

## Контекстная диаграмма

```
   ┌────────────┐        ┌──────────────┐
   │ Посетитель │        │ Администратор│
   └─────┬──────┘        └──────┬───────┘
         │ HTTPS                │ HTTPS (код доступа)
         ▼                      ▼
   ┌──────────────────────────────────────────┐
   │ server.py — FastAPI                      │
   │  /            страница приложения        │
   │  /quiz        квиз                       │
   │  /admin       админ-панель               │
   │  /api/auth/*  регистрация, вход, сессии  │
   │  /api/quiz/*  заявки                     │
   │  /api/admin/* модерация заявок           │
   └─────┬──────────────────────────┬─────────┘
         │                          │ опционально
         ▼                          ▼
   ┌────────────┐            ┌──────────────┐
   │ SQLite     │            │ SMTP (Gmail) │
   │ data.db    │            │ письма       │
   └────────────┘            └──────────────┘
```

## Логические границы внутри одного файла

Приложение намеренно остаётся одним модулем (`server.py`, ~750 строк), но внутри есть
разделение по ответственности. Оно зафиксировано, чтобы при росте файла было понятно,
что выносить первым:

| Блок | Ответственность | Что зависит от него |
| --- | --- | --- |
| Конфигурация (верх файла) | чтение окружения, `email_configured()`, флаги | всё остальное |
| Хранение (`init_db`, `get_db_connection`) | схема SQLite, идемпотентные `ALTER` | маршруты |
| Аутентификация (`hash_password`, `create_user_session`, `set_session_cookie`) | пароли, сессии, cookie | маршруты `/api/auth/*` |
| Квиз (`/api/quiz/*`) | валидация заявки, сохранение | админ-маршруты |
| Уведомления (`send_email`) | SMTP, выключено без конфигурации | квиз, админ |
| Keep-alive | пинг собственного URL | ничего (опция) |

Правило на будущее: при выделении модулей первым выносится хранение и
аутентификация — у них уже есть тесты (`tests/`), которые станут их контрактом.

## Границы поддержки

Заявлено: Python 3.11+, Linux/Render, браузер. Не заявлено: несколько реплик (SQLite на
файле, сессии в той же базе), другие СУБД, работа без файловой системы.
