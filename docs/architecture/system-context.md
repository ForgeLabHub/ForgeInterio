# Контекст системы

## Что это

Interio — небольшое веб-приложение для подбора дизайна интерьера: регистрация и вход,
интерактивный квиз, админ-панель заявок. Один процесс FastAPI, шаблоны и статика,
SQLite.

## Контекстная диаграмма

```
   ┌────────────┐        ┌──────────────┐
   │ Посетитель │        │ Администратор│
   └─────┬──────┘        └──────┬───────┘
         │ HTTPS                │ HTTPS (код доступа)
         ▼                      ▼
   ┌──────────────────────────────────────────┐
   │ app/ — FastAPI                           │
   │  /            страница приложения        │
   │  /quiz        квиз                       │
   │  /admin       админ-панель               │
   │  /api/auth/*  регистрация, вход, сессии  │
   │  /api/quiz/*  заявки                     │
   │  /api/admin/* модерация заявок           │
   └─────┬──────────────────────────┬─────────┘
         │                          │ опционально
         ▼                          ▼
   ┌────────────┐            ┌──────────────┐
   │ SQLite     │            │ SMTP (Gmail) │
   │ data.db    │            │ письма       │
   └────────────┘            └──────────────┘
```

## Модули пакета `app/`

Код разложен по ответственности; каждый модуль можно забрать в другой проект
по отдельности (карта заимствования — [../modules/module-map.md](../modules/module-map.md)).

| Модуль | Ответственность | Зависит от |
| --- | --- | --- |
| `app/config.py` | чтение окружения, `settings()`, адрес сервера | ничего |
| `app/db.py` | схема SQLite, соединение, курсор с коммитом | `config` |
| `app/security.py` | пароли, сессии, cookie, проверка роли, админ-код | `db`, `config` |
| `app/mailer.py` | SMTP, вложения, «почта выключена» без конфигурации | `config` |
| `app/models.py` | Pydantic-модели запросов и ответов | ничего |
| `app/routers/auth.py` | регистрация, вход, выход, текущий пользователь | `db`, `security`, `models` |
| `app/routers/quiz.py` | валидация и приём заявки, письмо в фоне | `db`, `mailer`, `models` |
| `app/routers/admin.py` | список заявок и смена статуса (только роль admin) | `db`, `security`, `models` |
| `app/routers/pages.py` | HTML-страницы и заглушки состояния сессии | `models` |
| `app/keepalive.py` | пинг собственного URL (опция) | `config` |
| `server.py` | `create_app()` + `uvicorn.run`, обратная совместимость импорта | всё |

Правило: HTTP-слой не ходит в базу «где придётся» — только через `app.db`, а правила
про пароли и сессии живут в одном месте (`app.security`).

## Границы поддержки

Заявлено: Python 3.11+, Linux/Render, браузер. Не заявлено: несколько реплик (SQLite на
файле, сессии в той же базе), другие СУБД, работа без файловой системы.
