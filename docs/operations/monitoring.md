# Наблюдаемость

| Сигнал | Где | Назначение |
| --- | --- | --- |
| `GET /` | приложение | health-check Render (`healthCheckPath: /`) |
| Логи stdout | процесс | ошибки маршрутов, сообщения keep-alive |
| Таблица `quiz_submissions` | SQLite | поток заявок и их статусы |
| Keep-alive лог | stdout, при включении | диагностика «усыпления» на бесплатном тарифе |

## Минимальные алерты

1. `/` не отвечает 2 минуты (Render сам перезапускает сервис).
2. Доля 5xx выше 1% за 5 минут.
3. Ошибки SMTP при заданных учётных данных.
4. Рост числа 409 при регистрации — возможен перебор или ошибка клиента.

## Чего нет

- Нет `/metrics`, нет трассировки, нет SLO.
- Нет структурированных логов: печать в stdout в свободной форме.
- Нет уведомлений о новых заявках, кроме письма (если почта настроена).
