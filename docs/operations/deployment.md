# Развёртывание

## Способы

| Способ | Файл | Комментарий |
| --- | --- | --- |
| Render.com | `render.yaml` | Python 3.11, `python server.py`, health-check `/` |
| Локально | `make run` | uvicorn на 8000 |
| Windows | `start.bat` | для локальной разработки |

## Порядок

```bash
cp .env.example .env      # задать ADMIN_CODE
make doctor
make install
make test                 # 15 тестов, сеть не используется
make run
make smoke-test           # в другом терминале
```

## Перед публикацией

1. `ADMIN_CODE` — длинный случайный код (не `ADMIN123`).
2. Если почта нужна — задать `SMTP_USERNAME`/`SMTP_PASSWORD` (новый пароль приложения,
   старый отозвать).
3. `CORS_ORIGINS` — точный домен, если фронтенд обслуживается откуда-то ещё.
4. `KEEP_ALIVE_ENABLED=true` только на бесплатном тарифе, который усыпляет сервис.
5. Файл `data.db` должен лежать на постоянном диске: на Render без подключённого диска
   база теряется при перезапуске. Это ограничение хостинга, а не приложения.
6. Один процесс: SQLite и сессии не рассчитаны на несколько реплик.

## Проверка после развёртывания

```bash
make smoke-test BASE_URL=https://<домен>
```

Smoke test отдельно проверяет, что `/api/admin/submissions` **не** доступен без прав —
это защита от регрессии эскалации привилегий.
