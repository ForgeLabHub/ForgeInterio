# Соглашения API

## Правила

| Правило | Деталь |
| --- | --- |
| Формат | JSON для `/api/*`, HTML для страниц |
| Аутентификация | cookie-сессия `session_id` (HttpOnly, SameSite=lax) |
| Админ-доступ | `/api/auth/admin-login` с кодом из `ADMIN_CODE`; без переменной — 503 |
| Валидация | Pydantic-модели + ручная проверка форматов (телефон, email) |
| Ошибки | `{"detail": "..."}` (FastAPI), коды 400/401/403/409/503 |
| CORS | `CORS_ORIGINS` (список через запятую); по умолчанию только same-origin |

## Маршруты

| Метод | Путь | Назначение |
| --- | --- | --- |
| POST | `/api/auth/check-phone` | проверка занятости номера |
| POST | `/api/auth/register` | регистрация, выдаёт cookie-сессию |
| POST | `/api/auth/login` | вход |
| POST | `/api/auth/admin-login` | повышение роли по коду из окружения |
| POST | `/api/auth/logout` | выход, удаление сессии |
| GET | `/api/auth/current-user` | текущий пользователь |
| GET | `/api/auth/users` | список пользователей (админ) |
| POST | `/api/session/save` | сохранение состояния квиза |
| POST | `/api/quiz/submit` | заявка квиза |
| GET | `/api/quiz/submissions` | заявки текущего пользователя |
| GET | `/api/admin/submissions` | все заявки (админ) |
| PUT | `/api/admin/submissions/{id}` | изменить статус (админ) |

## Коды ошибок

| Код | Когда |
| --- | --- |
| 400 | неверный формат (телефон, email), нет согласия, короткий пароль |
| 401 | нет/недействительна сессия, неверный админ-код |
| 403 | нет роли администратора |
| 409 | телефон или никнейм уже заняты |
| 503 | админ-вход не настроен (`ADMIN_CODE` пуст) |

## Как менять API

1. Изменить маршрут/модель. 2. Обновить `static/*.js`. 3. `make test lint` (тесты
описывают контракт). 4. Добавить строку в [verification/matrix.md](../verification/matrix.md).
